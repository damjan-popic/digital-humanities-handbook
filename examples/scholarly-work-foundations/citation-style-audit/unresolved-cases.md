# Unresolved citation cases

## Workbook as software or dataset

The teaching workbook can reasonably be described as software, a dataset or a supporting file, depending on how it is published and used. The generic Chicago quick guide does not by itself settle every repository or publisher convention for this hybrid object.

**Decision for the model:** describe the workbook with a corporate creator, italic title, version, year and repository URL, and label its nature in the surrounding prose. Before a real submission, ask the governing editor or instructor whether a software, dataset or miscellaneous CSL type is preferred.

## Generative-AI output

A citation cannot substitute for methodological disclosure. If an AI system materially affects prose, analysis, code or decisions, record the system, accessible version/date, task, relevant input/output provenance and verification practice as allowed by privacy and rights constraints. Follow the current venue policy because guidance and interfaces remain mutable.

## Local override

No local override is applied in this model. If one becomes necessary, add the dated instruction, its authority and an example to this file; then regenerate and re-audit the affected output.
