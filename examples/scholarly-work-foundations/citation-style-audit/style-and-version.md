# Citation style and version record

- **Authority chosen:** *The Chicago Manual of Style Online*, Notes and Bibliography: Sample Citations.
- **Authority URL:** https://www.chicagomanualofstyle.org/tools_citationguide/citation-guide-1.html
- **Authority accessed:** 2 September 2026.
- **System chosen:** notes and bibliography, not author–date.
- **Zotero style selected for the model exercise:** the current Chicago notes-and-bibliography style available in Zotero's style repository at the time of the exercise.
- **Zotero style-repository URL:** https://www.zotero.org/styles
- **Repository accessed:** 2 September 2026.
- **Local CSL label/version check:** record the exact label shown in your Zotero installation and the style's updated/version metadata before submission. The static sample does not claim that a mutable CSL file will retain one version indefinitely.
- **Local or institutional modifications:** none assumed. A journal, department or publisher-specific instruction overrides this generic exercise and must be cited separately.

The selected standard is appropriate here because the exercise models humanities notes and bibliography. It is not “better” than author–date; suitability depends on the governing venue and source types.
