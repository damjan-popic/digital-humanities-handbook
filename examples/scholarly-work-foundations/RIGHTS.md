# Rights and provenance

Version 1.0 was prepared for the *Digital Humanities Handbook* on 2 September 2026.

All catalogue records, prose excerpts, claims, tables, figures and validation notes in this sample pack are original teaching material created for the handbook. The catalogue describes fictional objects and collections. Text and data are released under CC BY 4.0; original build code in the repository is released under MIT, following the repository licence. No third-party screenshots, images or datasets are included.

The first three RIS records contain only bibliographic facts about publicly identifiable sources:

- Eric Hayot, *The Elements of Academic Style: Writing for the Humanities* (Columbia University Press, 2014), ISBN 978-0-231-16801-4.
- Steven E. Gump, review of Hayot's book, *Journal of Scholarly Publishing* 46, no. 4 (2015): 399–403, DOI 10.3138/jsp.46.4.BR2.
- Harvard College Writing Center, “Developing A Thesis,” a public guidance page.

The two remaining RIS records describe original files in this pack. Bibliographic facts are not copyrighted, but learners should verify them against the named sources. The pack reproduces no third-party source text and grants no right to redistribute attachments that a learner later adds to Zotero.
