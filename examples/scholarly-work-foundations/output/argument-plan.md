# Argument plan: normalization as an interpretive intervention

## Research question

How do documented normalization decisions change what a small fictional postcard catalogue allows a reader to find and compare?

## Provisional thesis

Normalizing object types and place labels improves comparison across inconsistent descriptions, but the cleaned table remains methodologically defensible only when it preserves source strings, names exclusions and exposes unresolved cases.

## Claim–evidence–reasoning sequence

1. **Claim:** inconsistent labels obstruct comparison. **Evidence:** four source expressions become two substantive normalized types plus `unknown`. **Reasoning:** grouping makes like cases countable, but this is a modelling decision rather than discovery of a natural category.
2. **Claim:** provenance limits the loss caused by normalization. **Evidence:** `place_raw`, `date_display` and validation notes remain beside normalized values. **Reasoning:** readers can inspect both the source expression and its analytical grouping.
3. **Claim:** visible exceptions make the summary more credible. **Evidence:** the impossible date and unknown type remain flagged; a duplicate and test row are named as exclusions. **Reasoning:** a transparent denominator prevents the chart from implying complete metadata.

## Counterargument and limitation

A reader may argue that preserving every source value makes the table harder to use. The response is to separate source and analytical fields rather than discard either. Because the corpus is fictional and very small, the exercise demonstrates a method; it does not support historical claims about cataloguing practice.

## Planned conclusion

The most useful cleaned dataset is not the smoothest one. It is the one whose transformations a reader can reconstruct and contest.
