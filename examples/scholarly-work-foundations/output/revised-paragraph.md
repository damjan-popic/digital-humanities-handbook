# Revised model paragraph

Normalizing catalogue labels can make inconsistent descriptions comparable without pretending that they were originally identical. In the teaching table, four source expressions are grouped as either *photograph* or *postcard*, while a blank value remains the explicit category *unknown* (Digital Humanities Handbook, “Fictional Postcard Catalogue Teaching Dataset,” version 1.0). The grouping supports a transparent count, but it also changes the data model: *Laibach* becomes *Ljubljana* for aggregation, for example. Retaining the source label beside the normalized value therefore matters as much as the transformation itself. As the accompanying teaching note puts it, a transformation may be repeatable without being defensible unless its assumptions are named (“Reading Notes,” B.1). This eight-record fictional exercise cannot establish how real catalogues behave; it demonstrates why a cleaned table should expose provenance, exclusions and unresolved cases.
