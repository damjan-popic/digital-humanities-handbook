# Reading notes for the fictional postcard-catalogue study

These notes and excerpts are original teaching material. Locators refer to sections in this file, not to an external publication.

## Note A — description and discovery

**Teaching excerpt (A.1):** “A catalogue field becomes an argument about similarity when it groups unlike descriptions under one searchable label.”

Description: The fictional raw table uses *Photograph*, *photo*, *Postcard* and *razglednica* for related object types.

Evidence: Eight retained records yield four postcard, three photograph and one unknown category after normalization.

Possible interpretation: Normalization can improve retrieval across variants, but the original expression should remain available because wording can carry historical and linguistic evidence.

## Note B — provenance of transformations

**Teaching excerpt (B.1):** “A repeatable transformation is not automatically a defensible one; its assumptions still need names, reasons and checks.”

Description: The proposed workflow removes one exact duplicate and one record whose identifier marks it as a test.

Evidence: The raw file has ten rows; the accepted cleaned table has eight. The validation note identifies both exclusions.

Possible interpretation: A refreshable query improves consistency, while a transformation log makes the scholarly decision open to criticism.

## Note C — transparent visual summaries

**Teaching excerpt (C.1):** “A chart is transparent only when a reader can recover its denominator, categories and exclusions.”

Description: The model chart summarizes normalized object types rather than the source strings.

Evidence: The chart denominator is eight retained records. Blank or unresolved source values are represented as *unknown*, not silently removed.

Possible interpretation: Showing the unknown category prevents visual certainty from exceeding the underlying metadata.
